# SafeStride

SafeStride does fall detection and gait-based fall-risk screening from one camera, on an edge GPU. It is built for the Embedded SF × CraftifAI hackathon (Problem #2, Track A). The pose engine is built and run in CraftifAI PipeGen. This repo's `logic/` package turns PipeGen's keypoints into fall alerts (JSON log and MQTT), gait metrics and a LOW / MODERATE / HIGH risk band.

SafeStride is a screening aid, not a medical device.

## Quick start

```bash
pip install -r logic/requirements.txt
python -m pytest logic/tests -q
python -m logic.demo --selftest
python -m logic.demo --source file:docs/demo_fall.jsonl --realtime
```

## Documents

- `logic/README.md`: how to run everything (PowerShell and bash).
- `docs/ARCHITECTURE.md`: data flow, modules, data contract.
- `docs/PROJECT_DESCRIPTION.md`: submission text (has `[FILL: ...]` items for the pipeline side).
- `docs/RESULTS.md`: measured results, generated by `python -m logic.make_results`.
- `docs/DEMO_SCRIPT.md`: the two-minute demo and the fallback plan.
- `NOTES.md`: engineering decisions, parameter values, limitations, open assumptions.
